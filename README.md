🌌 Galaxy Detection using Quantum Convolutional Neural Networks (QCNN)
This project demonstrates a novel approach to galaxy classification using Quantum Convolutional Neural Networks (QCNNs). By combining classical image processing techniques with the power of quantum machine learning, this work explores the potential of QCNNs to detect and classify astronomical images more effectively.

🔍 Overview
The main objective of this project is to utilize quantum circuits to mimic the feature extraction capabilities of classical CNNs, specifically for detecting galaxies. It involves loading and preprocessing astronomical datasets, building QCNN models using PennyLane, and analyzing their performance in comparison to traditional methods.

🚀 Highlights
✅ Implemented a hybrid QCNN architecture using PennyLane and NumPy.

🌀 Loaded and normalized astronomical image datasets.

📊 Compared accuracy, loss, and circuit depth to assess performance.

🔄 Integrated classical layers and quantum layers for hybrid learning.
